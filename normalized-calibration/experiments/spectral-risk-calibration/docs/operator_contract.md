## 1. 原稿口径（继承，不变）

候选超图 H 固定。节点独立律 P（n×C，行和为 1）。关系构造 h：

- `a_e = 1{ e 上全部预测同类 }`；
- `p_e = E a_e = sum_c prod_{u in e} P[u,c]`（`edge_retention_probability`）；
- `H_e = 1_e 1_e^T / |e|`；
- 原始关系算子 `B = B(a) = sum_e a_e H_e`（主线固定 w_e=1）。

两个受控臂（原稿模型 A/B）：

- A：`a_e = a_e(Y)` 由同一节点向量生成（共享节点依赖）；
- B：`b_e ~ Bern(p_e)` 独立边（边际匹配）。
  `E B_A = E B_B = sum_e p_e H_e` 精确成立（线性构造下）。

一阶影响分解（针对 B 的居中算子 X_A = B − E B，原稿 thm:decomp）：
`g_{e,u}(z) = prod_{v in e\{u}} P[v,z]`，
`F_u(z) = sum_{e∋u} (g_{e,u}(z) − p_e) H_e`，
`X_A = sum_u F_u(Y_u) + R`，`E[R | Y_u = z] = 0` 对每个 u、z。
（实现：原稿 `upgrade/node_influence.py`；本篇不重复其证明。）

## 2. 归一化算子（新口径，主对象）

固定 `w_e = 1`、`kappa = 1`（计划 §3.1）：

```
A(a)  = B(a) + kappa * I
D(a)  = diag( A(a) 1 )          # 每次抽样后重新计算，不用固定度近似
S(a)  = D(a)^{-1/2} A(a) D(a)^{-1/2}
```

性质（实现必须核验）：

- `D(a)` 对角元 `= kappa + sum_{e∋u} a_e >= 1 > 0`（含未覆盖节点），
  逆平方根良定；
- `S sqrt(d) = sqrt(d)`（一般不满足`S 1=1`），
  `lambda_max(S) = 1`，`||S||_2 = 1`（非负连通块上）；
- 未覆盖节点（度=kappa）在 `S` 与任何 `S` 的均值中心中对角元均为 1，
  居中后消去，不构成假性谱质量。

固定度对照（计划 §3.3，用于区分依赖效应与随机归一化效应）：

```
D_0 = diag( (E B + kappa I) 1 )      # 确定性
S_0(a) = D_0^{-1/2} A(a) D_0^{-1/2}
```

`E S_0 = D_0^{-1/2}(E B + kappa I) D_0^{-1/2}` 在 A/B 两臂精确相等
（D_0 确定、映射对 a 线性）。动态度下 `E S_A = E S_B` 一般不成立；
差值 `||E S_A − E S_B||_2` 必须单独报告，不得静默归入"依赖放大"。

## 3. 三个风险量（分开报告，计划 §3.2）

1. `R_1 = || B(a) − E B ||_2` —— 原始关系算子（原稿口径，继承）。
2. `R_2 = || S(a) − E S ||_2` —— 动态归一化后的中心化算子；
   `E S` 机制特定（A 臂与 B 臂分别中心化）。仅用于机制研究。
3. `T = || S_obs − M_hat ||_2` —— 可计算监测分数；
   `M_hat` 由独立参考批（真机制=节点律）算子均值估计并冻结。
   有限样本中心误差属于 `M_hat` 与 `E S` 的失配，单独记录，
   不得混入"依赖放大"。

## 4. 误差律三层级（计划 §3.4）

| 层级 | 随机来源 | 本篇用法 |
|---|---|---|
| L1 | 固定 H，节点预测按已知 P 独立抽样 | S1–S3 全部理论与 pilot |
| L2 | 独立参考批估计 `P_hat`，再独立节点重采样 | 后续；报告 TV 失配（T5） |
| L3 | 固定数据与协议、重复训练种子的整次预测向量 | A3/S8；需真实重训运行池 |

L1试点节点律使用完整已知标签定义人工错误机制，属于模型验证，不解释为部署时无标签的误差律估计：

- `binary-eps`：原稿 `majority_binary_profile`（多数类编码为类 1，
  多数节点翻转概率 eps，其余 eps）；eps ∈ {0.05, 0.15}。
- `multiclass-eps`：原稿 `multiclass_profile`；eps ∈ {0.05, 0.15}。
- `hetero-eps`：按度分层的异质错误率（低度 eps_lo、hub 区 eps_hi），
  显式已知（计划 A2 要求"异质节点错误率"设置）。

训练种子变化 ≠ 训练划分变化。S7随机标签集，S8含split/crossfit随机；S11另用固定20%标注节点、只换初始化的GCN（Cora500ep/DBLP120ep），不合并为同一机制。

## 5. 抽样与校准程序（计划 §4）

抽样（保留共享节点依赖，不做"先抽节点再独立化边"）：

```
对每次 b：
  1. Y^(b) ~ 独立节点律 P（完整预测向量）
  2. a^(b) = h(Y^(b)) 同时生成全部边
  3. D^(b) = diag(B(a^(b)) + kappa I)1  重新计算
  4. S^(b) = D^{-1/2} A D^{-1/2}；T_b = || S^(b) − M_hat ||_2
```

三批隔离（种子流互不相交，批间独立）：

- Reference：确定全部超参数、节点律、冻结中心 `M_hat`
  （= 参考批 S 算子的逐项均值，模式固定、数据均值）；
- Calibration：只产分数定阈值；
- Evaluation：只算超越率与检出率；不更新模型与阈值；不读取测试真类。

有限样本秩阈值（计划 §4.4，升序 `T_(1)<=...<=T_(M)`）：

```
k = ceil((M+1)(1−alpha))
q_alpha = T_(k)  若 k <= M，否则 +inf
超越判据：严格 T_new > q_alpha
```

并列存在时该规则通常保守（实现须含并列压力测试）。保证等级标签
只允许以下五种（T6），每张结果表逐格标注：
① 指定模型解析界；② 指定模型内有限样本秩保证；③ 同一重复运行机制
交换性保证；④ 数值/经验结果（含已知律MC与拟合律）；⑤ 跨机制失配压力测试。

Pilot 预算（计划 §4.3 试点档）：Reference 200 / Calibration 500 /
Evaluation 1000；确认档 1000 / 2000 / 5000。alpha 主目标 5%，
敏感性 1%、10%。

## 6. 校准器（计划 §7，pilot 必含）

同一冻结 `M_hat` 与同一分数定义下，只差抽样机制：

- `edge-iid`：a_e ~ Bern(p_e) 独立（重现原稿失准现象的基线）；
- `node`：完整节点向量重抽样（保留共享节点依赖；L1 下即真机制）；
- `run-pool`：独立训练运行生成完整预测向量，参考/校准/评价按运行隔离（S7/S8/S11）。从有限池反复有放回抽样不自动等价于新训练运行的交换性保证。

秩保证给定独立参考阶段，对校准集和新观测联合取概率；不保证给定某次校准集后的条件率≤α或等于α。CP区间针对一次冻结阈值的条件率。S3区间端点包络不是合并95%CI；S12-C1改用条件Hoeffding。

中心补充：S2各臂自身中心化；S9a/S10a使用共同确定性基点S(p)，一般S(p)≠ES，不得视为自身中心化波动。

L1 下 evaluation 一律从真机制（节点律）抽取；`node` 校准器即
"真模型内自校准"参照，`edge-iid` 是失配对照。

## 7. 数值口径（计划 §9-A0）

- 小图（n ≤ 600，代码DENSE_LIMIT）：稠密 `eigvalsh` 双端谱范数；全状态枚举
  （节点枚举 ≤ 2^14 / 3^8，边枚举 ≤ 2^14）算精确 `E S`、精确
  `E[S|Y_u=z]`、F_u^S 分解与剩余项正交性核验。
- 大图：`scipy.sparse.linalg.eigsh`双端，固定起点。n>20000时tol=3e-6/maxiter=300，其他tol=1e-8/maxiter≤1500。
  API返回残差，但历史调用者未完整保存逐分数诊断，不能声称已有完整approx标记。
  不收敛且无部分特征值时返回Frobenius替代分数/resid=inf；部分值可能不含极端值。
  校准与评价共用同一确定性近似流程，其秩保证作用于该近似分数；
  不自动保证真实谱范数；小残差也不是极端特征值证书。DBLP异常未排除其他阶段受影响，没有完整缓存时保留此限制。
- 中心 `M_hat`：固定模式上数据数组的批均值（精确可加），大图无需
  保存 R 个算子。

## 8. 禁止事项（照抄计划 §2 纪律）

下界大不等于已有上界；中心化谱范数下降不等于分类改善；模拟样本多
不等于误差律不确定性消失；对独立边模型校准失败不等于证明了某实际
系统的错误告警。
