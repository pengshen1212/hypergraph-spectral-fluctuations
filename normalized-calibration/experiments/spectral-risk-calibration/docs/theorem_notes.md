## T1 归一化条件影响分解（经典分解的应用）

独立坐标Y_u下，令X=S(Y)−ES(Y)，F_u=E[X∣Y_u]，R=X−Σ_uF_u。
算子有界，Frobenius空间内二阶矩存在。E F_u=0；u≠v时坐标独立给出
E[F_v∣Y_u]=0，所以E[R∣Y_u]=0。Frobenius内积满足
E⟨F_u,F_v⟩=0、E⟨F_u,R⟩=0，故

`E‖X‖_F² = Σ_u E‖F_u‖_F² + E‖R‖_F²`。

二分类时Δ_u=E[S∣1]−E[S∣0]，F_u(1)=P0Δ_u、F_u(0)=−P1Δ_u，
v_u=P0P1‖Δ_u‖_F²。证明对全部节点成立；小图枚举是实现核验，
native子集不能替代全节点恒等式。这是经典条件期望分解的应用。

## 秩保证的概率对象

冻结独立参考阶段后，校准分数T_1,…,T_M与新分数T_new交换，
k=ceil((M+1)(1−α))，q=T_(k)（k>M时为∞），则

`P(T_new>q ∣ reference) ≤ α`。

无并列时新分数的升序秩在M+1个位置均匀，超越事件有M+1−k个位置；
并列的保守处理只减少超越。概率对校准集与新观测联合取平均，
不是给定某次校准集仍有条件率≤α。连续律下边际率为(M+1−k)/(M+1)，
也不必等于α。双侧秩p值以2min(p_up,p_lo)检验时，用各侧α/2有效性与并集界。

S12-C1不同阈值的条件率可不同，合并CP不成立。给定三批全部参考/校准工件，
N个独立有界评估指标满足Hoeffding：

`|p_hat−Σ_i p_i/N| ≤ sqrt(log(2/δ)/(2N))`，至少1−δ条件概率。

对象是三批阈值的样本量加权条件率，不是重抽校准集的边际覆盖。

## T4 归一化扰动工程引理 —— 完整证明（已完成）

**引理 T4.** 设 `A, A'` 对称、元素非负，`D = diag(A 1)`、`D' = diag(A' 1)`，
`d0 = min(min_u D_uu, min_u D'_uu) > 0`。记 `S = D^{-1/2} A D^{-1/2}`、
`S' = D'^{-1/2} A' D'^{-1/2}`。则

```
||S - S'||_2 <= ||A - A'||_2 / d0  +  ||A'||_2 * ||D - D'||_2 / d0^2 .
```

**证明.** 三项三角拆分

```
S - S' = D^{-1/2}(A - A')D^{-1/2}
       + (D^{-1/2} - D'^{-1/2}) A' D^{-1/2}
       + D'^{-1/2} A' (D^{-1/2} - D'^{-1/2}).
```

第一项：`||D^{-1/2}|| <= d0^{-1/2}`（各度均 ≥ d0）给出
`<= ||A - A'||_2 / d0`。

对角逆平方根的标量 Lipschitz：对 `x, y >= d0`，中值定理
`|x^{-1/2} - y^{-1/2}| = (1/2)xi^{-3/2}|x - y| <= |x - y| / (2 d0^{3/2})`，
故 `||D^{-1/2} - D'^{-1/2}||_2 <= ||D - D'||_2 / (2 d0^{3/2})`。

第二、三项各 `<= ||D - D'||_2/(2 d0^{3/2}) * ||A'||_2 * d0^{-1/2}`
= `||A'||_2 ||D - D'||_2 / (2 d0^2)`，合并得引理。∎

**本篇应用（v1.1 修正，评审第三轮指出）.** `A = B + kappa I`，
`kappa = 1`：度 = `kappa +` 激活边数 ≥ kappa，故 `d0 >= kappa`。可将界中d0替换为已知下界kappa取得更保守的界，不将实际最小度恒等于kappa。

节点替换差分**不**满足“每个节点度变化≤1”：翻转节点 u 的预测会同时改变
所有关联边 e∋u 的激活状态，任意节点 v 的度变化为
`Δd_v = Σ_{e∋v, u∈e} Δa_e`，其绝对值上界是**共现边数** `co(u,v)`
（≤ min(deg(u), deg(v))）；u 自身的度变化可达 deg(u)。因此 T4 第二项实际为
`||A'||_2 · max_v co(u,v) / d0^2`，**随替换节点的度数增长**——对 hub 替换
（真实链条中正是放大来源）这一项不可当作常数。

引理本身（三拆分 + 逆平方根 Lipschitz）仍成立且保存的数值核验 0 违例；
**引理与其应用说明分开审计**：引理的各因子均已正确使用，错误在于把
`||D-D'||_2` 当成 O(1)。该错误使“T4 给出不随 m 增长的保守控制”这一应用
结论失效。T4对任意正度矩阵仍适用，节点替换时必须保留co(u,v)因子。包含v=u时max_v co(u,v)=deg(u)，低共现不能绕过替换节点自身的度数。
使用位置：T3 鞅路线的输入界、低度节点敏感性定位（低度侧错误结论不受影响，
因为那里 co(u,v) 小）；hub 侧不得引用“常数第二项”。

**数值核验.** familyA / familyB_max / cora-cc / dblp-ca 上随机 flag 对：
最大 `LHS/RHS` 比值与违例计数见 `theory_checks.json`（violations 必须为 0）。

